# 小程序动作、数据与门禁验收

复核日期：2026-11-19（America/Los_Angeles）。范围为本次交付的16个uni-app原生页面，及其共享路由、Axios适配器、会话、分页、微信原生动作封装。

## 逐页操作与保存位置

| 页面 / 原生路由 | 可执行操作 | 服务端或原生接口 / 数据落点 | 门禁与失败恢复 |
|---|---|---|---|
| 首页 `/pages/index/index` | 商品搜索、分类、加载更多、详情、邀请分享、下拉刷新 | `GET /products/page`、`/categories`、`/config`、`/rules/public`；读取真实商品/SKU数据 | 公开读取不依赖可选会话恢复；加载、空数据、失败与重试分开；邀请码先规范化再保存 |
| 积分商品 `/pages/catalog/points` | 按可抵积分商品浏览、搜索、分类、分页、详情 | `GET /products/page?points=true`；会员积分来自`/me` | 无登录可浏览商品；积分数量只有成功读取会员资料后展示；失败可重试 |
| 商品详情 `/pages/product/detail` | 选规格、调数量、加购物袋、立即购买、分享 | `GET /products/{id}`、`PUT /cart/{sku}`；`cart_item`持久化 | 无库存禁止购买；购物动作需会员，登录后保留商品返回路径；商品不可读有重试与回目录入口 |
| 购物袋 `/pages/cart/index` | 调数量、删除、进入商品、结算、刷新 | `GET /cart`、`PUT /cart/{sku}`；服务端购物袋 | 会员身份；已有数据与空袋分开，首次读取失败不显示为“空袋”；写入成功后补刷失败不撤销已接受的写入 |
| 结算 `/pages/checkout/index` | 选地址、新增地址、积分抵扣、留言、同意规则、提交订单、刷新报价 | `/addresses`、`POST /checkout/quote`、`POST /orders`＋幂等键；`quote/shop_order/order_item` | 有效会员、地址、服务端报价、规则同意；地址/购物袋读取失败提供重试，报价失效禁止提交；创建成功后补刷失败不阻断订单跳转 |
| 订单列表 `/pages/orders/index` | 状态筛选、加载更多、订单详情、下拉刷新 | `GET /me/records/orders` | 服务器按当前会员隔离；分页不受旧100条截断；失败保留已读数据并重试 |
| 订单详情 `/pages/orders/detail` | 原生支付、网页支付链接复制、查单、取消、收货、物流、分项售后、返回列表 | `/orders/{no}`、`/prepay`、`/payment-status`、`/cancel`、`/receive`、`/logistics`、`POST /refunds` | 所属会员校验；初次失败不再空白；取消核对中禁止再次支付；已选Native/H5的订单不当作JSAPI支付；付款成功以服务端查询/回调为准 |
| 我的账户 `/pages/account/index` | 手机/微信/开发登录、编辑昵称、退出、资产类型筛选、账本分页、账户功能菜单 | `/auth/phone/*`、`/auth/wechat`、`/auth/dev`、`PUT /me`、`/auth/logout`、`/me/records/ledger` | 手机登录需协议和有效挑战；开发入口仅服务端dev模式；网络错误保留既有会话状态，不误当新注册；退出清除私有分页资料 |

| 实名 `/pages/account/identity` | 单独同意、姓名/身份证核验、脱敏状态查询、冷却后显式重试 | `GET/POST /me/identity`；服务端加密的实名记录 | 仅支持姓名与身份证二要素；原文只在表单内存，提交/隐藏/卸载清理；PENDING按服务端retryAfter等待；模拟结果明确标记，不能用于生产提现 |
| 地址列表 `/pages/addresses/index` | 新增、编辑、删除、导入微信地址、下拉刷新 | `/addresses`；原生`chooseAddress`只导入内存草稿 | 会员身份；原生隐私拒绝不读取地址；读取失败不伪显示为“没有地址”；删除确认后再持久化 |
| 地址编辑 `/pages/addresses/edit` | 编辑已有地址、手动新增、设置默认、保存 | `POST /addresses`；服务端所有权校验、默认地址状态 | 已有地址未读取成功时禁止保存，防误当作新增；无效ID/读取失败可返回或重试；草稿仅内存、同会话且只消费一次 |
| 推广 `/pages/promotion/index` | 同意推广规则、成为分享者、复制邀请码、原生分享、两级邀请切换/搜索/分页、佣金状态筛选 | `POST /me/promoter`、`/me/records/{commissions,invites,second-invites}` | 成交规则由服务端版本及环境开关控制；统计使用全量summary，不能累加当前页冒充总额；私有页不显示被邀请人的地址/手机/证件 |
| 提现 `/pages/wallet/withdraw` | 填金额申请、筛选记录、分页、刷新、原生确认收款 | `POST /me/withdrawals`＋幂等键、`/me/records/withdrawals`、`wx.requestMerchantTransfer` | 身份、真实微信绑定、提现开关与服务端余额/双人复核；金额按字符串转整数分；原生确认不代表到账，保留服务端最终状态；旧微信版本/缺包明确报错 |
| 规则/客服 `/pages/legal/index` | 查看隐私、交易、分销规则、客服资料，复制联系方式 | `/config`、`/rules/public`；原生剪贴板 | 数据未读成功时不把零值显示为真实规则，也不复制空联系方式；失败有可见重试；联系人来自配置 |
| 月度奖励 `/pages/account/awards` | 历史核准奖励分页、刷新、进入提现 | `GET /me/records/awards`；只查询APPROVED记录 | 需会员，草稿或待复核奖励不当作已入账；开关关闭仍可查看既有核准记录 |

## 共同安全与恢复行为

- 每个命名路由均在`pages.json`中注册；需要会员的页面在进入和刷新时检查会话，登录返回地址只接受本项目注册路径。
- 页面和组件通过领域API调用封装的Axios；公开认证请求不携带旧会员令牌，旧请求的401不能注销新登录账户。
- 私有分页记录绑定原始令牌和请求代次，旧筛选/旧账户响应不能覆盖新状态；退出和会话失效清理私有数据。
- 服务端分页回到有效末页时（例如订单状态变化使最后一页消失），客户端重新读取集合，避免追加重复记录或陷入永久重试。
- 报价、库存、身份、所有权和提现权限均由服务端最终判断；本机按钮禁用不代替服务器门禁。
- 微信支付回调、付款取消、商家转账确认原生回调都不直接改余额或订单为成功，仍由服务端可信渠道事实更新。
