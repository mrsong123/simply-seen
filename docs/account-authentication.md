# 手机登录与实名认证

## 登录、注册与账户关联

网页和小程序使用手机号＋短信验证码登录，首次验证通过自动注册，无需另设会员密码。用户先同意服务与隐私条款；新会员可带邀请码，已注册账户不因再次登录修改上级或重新分配资产。

已有微信会员应先使用微信登录，再进入账户安全绑定手机号。以后输入该号码会回到原会员，保留订单、积分、佣金及邀请关系。新手机账户可在小程序使用微信登录凭证绑定微信。手机号或微信身份已被另一会员占用时，系统明确拒绝，不自动移动订单、余额或分销关系。已绑定号码不提供未经旧号码核验的直接覆盖入口。

管理员仍使用独立账号密码；手机号验证码不授予任何管理权限。被停用的会员不能通过切换登录方式重新启用。

| 接口 | 用途 |
|---|---|
| POST /api/v1/auth/phone/code | 获取登录验证码挑战 |
| POST /api/v1/auth/phone | 验证码登录或首次注册 |
| POST /api/v1/me/phone/code | 为当前会员获取初次绑定验证码 |
| POST /api/v1/me/phone | 验证并绑定手机号 |
| POST /api/v1/me/wechat | 小程序将真实微信身份绑定到当前会员 |
| GET /api/v1/me/identity | 查看脱敏实名认证状态 |
| POST /api/v1/me/identity | 明确同意后提交姓名/身份证信息核验 |

挑战与手机号、用途及绑定会员关联，登录验证码不能用于绑定他人账户。验证码使用后失效；过期、错误次数用尽或重发后应重新获取。敏感失败计数不会随业务异常回滚；数据库唯一约束和领域锁处理并发账户占用。

## 实名认证

用户在账户安全页填写真实姓名和18位大陆居民身份证号，阅读用途并明确同意后提交。服务端先检查格式、出生日期和校验位，再调用阿里云Id2MetaVerify进行姓名/证件信息匹配。客户端校验或身份证校验位正确本身不能让用户变成已实名。

结果包含UNVERIFIED、PENDING、VERIFIED、REJECTED及development标记。请求超时、供应商异常和未知结果不会当作匹配成功；前端展示可理解的状态与重试方式。生产只认可真实服务商的明确成功。姓名、证件密文不下发客户端，界面仅显示脱敏姓名、证件及认证时间；原始资料不放入浏览器localStorage、Pinia持久状态或日志。

处理中可查询结果；渠道未给出明确结果时，默认120秒租约后允许重新提交，仍受每日次数限制。服务端返回retryAfter秒数用于显示当前剩余冷却，前端不能以倒计时结束替代服务端授权。

该功能是二要素信息匹配，不包含人脸活体或微信收款人同名核验。开发环境页面明确标记模拟结果，不能用于证明真实身份，也不能通过切换生产配置获得真实提现资格。

## 提现和支付

提现申请与管理员执行均检查实名门禁；生产始终要求真实认证及真实微信绑定，不能通过关闭前端提示或把配置改false绕过。申请阶段不合格不会冻结余额；执行时再次核对，避免审批后状态变化产生出款。

手机号账户可以登录、管理地址和订单；当前实际收付渠道为微信小程序。未绑定微信的生产账户请求预支付会收到WECHAT_BINDING_REQUIRED，应在小程序使用同一手机号登录并绑定微信。该检查发生在标记预支付及外调前。

## 配置与验收

完整变量和服务商端点见[配置清单](configuration.md)。生产必须使用aliyun模式，开通短信模板和身份核验产品，固定保存ACCOUNT_DATA_KEY。local可无商户账号启动：短信仅返回明确标记的当次随机测试码，实名结果仅模拟，生产拒绝此类验证码和认证结果。

真实服务商验收应在受控环境使用经同意的测试手机和身份资料，确认短信到达、错误/过期/重放拒绝、匹配/不匹配、账户占用冲突及提现门禁。自动化测试使用显式开发模式或受控渠道响应，不代表已在实际阿里云账号完成收费产品联调。

阿里云请求及响应判据核对自官方SDK源码：短信[dysmsapi20170525 4.6.0](https://repo.maven.apache.org/maven2/com/aliyun/dysmsapi20170525/4.6.0/dysmsapi20170525-4.6.0-sources.jar)、实名[cloudauth20190307 3.14.2](https://repo.maven.apache.org/maven2/com/aliyun/cloudauth20190307/3.14.2/cloudauth20190307-3.14.2-sources.jar)、经典RPC签名[aliyun-java-sdk-core 4.7.10](https://repo.maven.apache.org/maven2/com/aliyun/aliyun-java-sdk-core/4.7.10/aliyun-java-sdk-core-4.7.10-sources.jar)。适配器采用原生HTTPS与签名，不要求安装这些SDK依赖。
