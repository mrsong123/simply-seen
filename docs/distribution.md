# DIST-1.0 两级成交分销规则

本规则是根据本次“设计并实现二级分销”的要求制定的工程基线，替代旧文档80%待释放与消费解锁模式；上线启用仍以运营主体实际资质、规则公示及财务法律审核为准。

## 归因

会员在首次微信注册时可以提交邀请人的专属码；已有会员登录不修改归属。邀请人必须已接受推广规则且账号未停用。新账号只指向已存在账号，数据库不存在后绑或换绑接口，因此关系按创建时间严格向前，不会自邀或形成环。只计算父、祖父两层，不向上递归计酬。订单创建冻结当时有资格的受益人和规则版本；未成为推广者的一层不享受该层佣金，也不把该层份额递补给上层。

加入不收费，不要求购买、充值、囤货或维持业绩；注册、招募推广者本身不计现金报酬。用户只能查看归因会员昵称、加入时间与本人佣金，不开放下级手机号、地址或微信标识。

## 计算

全部计算使用整数分。对每个订单行：

```
lineCash = 行商品金额 - 该行积分抵扣面值
lineMargin = max(0, lineCash - 数量 × 成本快照)
linePool = min(floor(lineCash × 商品佣金上限 / 100),
               floor(lineMargin × 毛利可分配比例 / 100))
orderPool = sum(linePool)
monthRoom = max(0, 规则月预算 - 本月已生成佣金原始金额合计)
usablePool = min(orderPool, monthRoom)
first = floor(合格商品现金 × 一级基点 / 10000)
second = floor(合格商品现金 × 二级基点 / 10000)
if first + second > usablePool:
  first = floor(usablePool × first / (first + second))
  second = usablePool - first
```

积分抵扣和运费不计佣。不存在有资格的受益人时，该层金额不入账；预算不足会降低实际佣金，不能宣称固定到手比例。初始一级500基点、二级200基点，合计7%；规则护栏合计≤10%，商品佣金上限≤10%，毛利分成≤50%。创建佣金时锁定规则行，串行核验预算。初始月预算10000元，预算按上海时区、当前生成月份保守占用；已冲回原始佣金仍占用该月预算，避免退款刷额度。

示例：商品现金129元、成本42元、运费6元；商品上限7%，毛利可分配30%。佣金池9.03元，一级6.45元、二级2.58元，运费不参与。

## 结算

支付渠道确认成功后生成PENDING佣金，未确认支付不计佣。订单确认收货后，至少等待规则规定天数（初始7天，允许7至90天），且无进行中的售后，才能结算。被停用的受益账号暂停结算。定时任务和重复事件均受唯一键约束。

待结算不是可提现余额。结算时先抵偿历史追偿负债，余额进入可用佣金；再由提现流程冻结、审核、执行和渠道核实出款。自己购买不会给自己计佣，不需要再次购买或邀请解锁佣金。

## 退款

退款先审核、再提交原路退款，最终以渠道成功为准。各次退款按原订单行现金及积分比例分摊，最后一件吸收余数；最后一次全部商品退完时退回原运费。累计退款现金/积分/商品数量不得超原始快照。

佣金按来源订单剩余合格商品现金同比例缩减。未结算佣金直接减少；已结算部分先冲回可用佣金，不足部分记正数追偿负债并生成异常工单，绝不把可用余额写为负数。已转账、提现冻结和税务处理保留原事实，由财务复核追偿。新佣金可抵偿待追偿款项。全退佣金状态REVERSED。

赠送积分按退款后有效净现金重新计算，已使用积分不足回收时生成积分追偿工单，暂停该用户新的提现申请，人工核销后恢复；现金与积分缺口不会混成同一资产。

## 月度优惠权益

独立开关，默认生产关闭。按Asia/Shanghai自然月，只结算已结束月份。当前设计是按当月商品净现金实付合计排名，非保证“某订单全额免单”。合格会员人数的前10%向上取整；相同业绩按首次有效支付时间、会员ID升序打破平局。预算取合格业绩10%与规则已批月预算两者较小值，依排名分配，每人金额取其有效业绩、500元和剩余预算三者最小值，不足可部分奖励。

先生成DRAFT；与经办人不同的财务审批后，优惠权益进入可用余额，实际转账仍走提现流程。草稿后退款使草稿INVALIDATED，可重建；已审批后退款保留历史并生成工单。该分配方案是本次明确采用的设计选择，不再沿用旧文档中的未决算法占位。
