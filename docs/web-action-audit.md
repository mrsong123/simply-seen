核对日期：2026-11-20。范围包括商城、会员中心、手机号与实名、网页支付及运营后台。表中“数据”说明实际调用与持久化归属；界面没有通过定时器伪造付款、认证、发货或入账成功。

## 网页支付

1. 桌面默认NATIVE；移动端且`WX_WEB_PAYMENT_MODE=h5`时选择H5。已有通道锁定时按原通道恢复，避免同订单跨产品重复发起。
2. `orderApi.prepay`使用封装后的`request.post()`，传`channel`。NATIVE凭证生成可扫描及可保存的真实二维码；H5使用后端校验过的HTTPS地址。
3. 显示订单号、应付金额和凭证倒计时。每5秒查单，自动查询最多60次，后台标签页暂停网络查询；保留显式人工查单。
4. 只有当前订单的后端状态变化才更新订单，既不因二维码生成、跳转离站、计时结束，也不因别的订单结果显示付款成功。
5. 关闭弹窗、切换路由和组件卸载停止旧轮询。过期、关闭中、渠道暂不可用均有可理解状态和恢复动作；不对已过期订单反复生成不可用付款码。
6. 小程序已经发起的JSAPI订单，在网页保留原入口说明、查单及取消；不会把JSAPI参数伪造成网页二维码。

## 后台动作

后台路由先验证管理会话及角色，API再次强制授权。角色缩写：A=ADMIN、O=OPERATOR、F=FINANCE。各列表使用`/admin/records/{kind}`的全库搜索/状态筛选/分页，导出明确为**当前筛选页**，保留CSV公式转义。

| 页面 | 动作及真实数据 | 页面/操作门禁 |
|---|---|---|
| 经营概览 | `/admin/summary`读取成交、会员、待办、趋势；刷新及待办跳转 | A/O/F；各待办目标按角色显示 |
| 商品管理 | 新建/编辑商品、上下架、精选、价格成本库存、增加/移除SKU、撤销未保存移除、历史停用SKU、分类新增/编辑 | A/O；预占SKU不能移除，至少保留1个有效规格；分类失败可重试 |
| 订单与履约 | 搜索全部订单、详情、发货录入物流公司/运单；`/admin/orders/{no}/ship`后回读 | A/O/F可读；仅A/O对可发货订单操作 |
| 售后退款 | 来源订单、审核通过/驳回、填写依据；`/admin/refunds/{id}/review` | A/O/F可读；财务操作依角色显示，服务端再次授权 |
| 会员管理 | 分页/搜索、停用/恢复会员；`/admin/members/{id}/block` | A/O/F可读，A操作；确认提示撤销会话及保留账务 |
| 成交佣金 | 全库受益/来源记录、状态筛选、翻页/导出；真实待结算/已结算/已冲回 | A/F |
| 资产账本 | 全库流水搜索、分页/导出；按资产单位格式化整数金额 | A/F；没有任意改余额入口 |
| 提现与出款 | 财务审核税额/理由、另一管理员执行、提交中/未知/待确认原单查询；`review/execute/query` | A/F审核；A执行且本人不是审核人；开发测试确认仅开发显示 |
| 活动与分销规则 | 查看版本字段、创建待复核草稿、另一管理员批准生效 | A/O创建，A审批且本人不是经办人；F只读 |
| 月度优惠结算 | 生成指定历史月份草稿、候选金额/预算明细、异人复核入账 | A/O生成，A/F复核且本人不是经办人；关闭活动时历史仍可查 |
| 对账与异常 | 执行实际对账、对账批次/差异/异步任务分页切换、工单处理依据 | A/F；未知渠道结果保留差异，不伪造通过 |
| 账号与权限 | 新增A/O/F账号、停用/启用、重置密码；当前账号修改自身密码 | A；不提供当前会话直接停用自己的控件，服务端保护最后管理员 |
| 操作审计 | 全量搜索、分页/导出、审计详情 | A/F；展示业务事实，无删除或修改审计按钮 |

## 通用恢复与敏感数据

- 加载、空列表、加载失败是不同状态；失败提供实际重载，保存后失败提示不会编造保存成功。
- 商品、后台资源、订单和分页均有请求代次保护；过期响应不能覆盖新路由，旧会话401不能清除刚切换的新会话。
- 原始实名资料、短信凭据不写入Pinia持久状态/localStorage；API与验证码开发模式有明确区分。
- 所有业务HTTP经`api/* → utils/request`；二维码和CSV属于浏览器本地生成的真实产物，不替代服务端交易事实。
- 未配置或未开放的外部业务明确禁用/报错。正式使用仍需有效商户产品权限、域名、证书及服务商凭据；这些条件不能由受控界面响应或编译成功推断成立。
