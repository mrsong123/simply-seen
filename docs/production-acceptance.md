# 生产分支协议验收

`ProductionProtocolTest`使用`prod`配置、`APP_DEV_MODE=false`、真实MySQL以及实际Controller、Service、Mapper和数据库迁移。它不调用开发付款、开发实名、开发转账等快捷入口，也不通过关闭实名认证或权限检查让测试通过。

## 渠道与证据

测试供应商是仅存在于`server/src/test`的本地HTTPS服务器。每轮临时生成带localhost SAN的证书，以及相互独立的商户RSA密钥、微信平台RSA密钥。测试HTTP客户端只信任该轮证书，保留主机名验证；没有关闭TLS校验，也没有向生产代码添加模拟成功开关。

| 通道 | 验证内容 |
|---|---|
| 阿里云短信 | 实际HTTPS POST、经典RPC HMAC-SHA1签名、版本/签名/模板、6位验证码结构；验证码只在测试服务器内存中读取，不以devCode响应返回 |
| 阿里云实名 | 实际HTTPS POST及签名，Id2MetaVerify与明确匹配结果，最终实名development=false；不是开发模式自动认证 |
| 微信登录 | 通过实际HTTPS code交换取得对应测试openid，再使用正常账户绑定接口 |
| JSAPI/Native/H5 | 实际HTTPS请求的商户RSA签名与字段、平台签名响应、前端JSAPI签名、Native二维码、H5受控返回地址 |
| 支付通知 | 平台RSA验签、AES-256-GCM解密、商户/应用/原单/金额/币种、重复通知幂等；错误签名不能入账 |
| 退款 | POST/GET使用status，通知使用官方refund_status和mchid；缺少通知币种时查询同一原退款单的完整可信证据，正确签名但商户/原支付交易号不一致的通知仍拒绝 |
| 商家转账 | 创建响应没有金额/身份字段，GET没有package_info，通知没有appid；据此验证创建、查单、确认包保留和最终证据核销。受控供应商用平台私钥解密user_name确认实名资料确实加密传输 |

Controller由MockMvc驱动；供应商方向使用实际TLS网络。阿里云与微信测试bean只注入本轮受信HTTP客户端，避免受管环境的外部代理截获localhost流量，业务规则、请求签名、响应验签及解密均使用正式实现。测试没有证明真实商户或真实身份数据库已授权、已开通或已验收。

## 业务闭环

用例实际创建管理员、财务、运营和独立出款执行人，通过短信注册两级邀请链，创建分类、商品、SKU、地址、报价和订单，然后完成：

1. 未绑定微信的手机号会员发起Native支付，重复预付复用同一意图，签名/加密通知确认付款。
2. 生成两级佣金，后台发货、买家确认收货，售后观察期结束后结算。
3. 未实名提现被拒绝且不冻结资金；真实通道模式的二要素结果通过后申请提现。
4. 财务审核、另一管理员执行；等待用户确认时保存微信确认包，查单缺少该字段不能清空它；最终通知重复到达不重复扣款。
5. 已出款后退款，剩余佣金冲回，不足部分形成追偿负债；官方退款通知触发完成并保持幂等。
6. 独立JSAPI订单确认实际付款人绑定，第二次结算先抵偿历史负债。
7. H5订单取得实际跳转参数，未付款取消后释放库存预占。
8. 月度草稿须异人复核，审批入账后执行账本和支付/退款/转账渠道对账。

测试会把已经实际支付并收货的测试订单时间移至上一个月，以验证七天观察期与历史月份结算，不等待真实日历时间；不直接伪造余额、账本或支付成功状态。

## 运行

必须使用**可清空的专用MySQL测试库**。测试仅在`TEST_DATABASE_URL`以`jdbc:mysql:`开头且数据库名以`test_`开头或`_test`结尾时启用；普通无MySQL的H2构建会明确跳过此专用用例。测试会清空应用业务表，不得指向生产库。

设置`TEST_DATABASE_URL`、`DATABASE_USER`、`DATABASE_PASSWORD`后执行：

```bash
./mvnw -DAPP_CONFIG_FILE= -f server/pom.xml -Dtest=ProductionProtocolTest test
```

只有JRE21的受管云环境显式增加`-Pcloud-ecj`。完整JDK21使用默认javac。无需真实服务商凭据，临时密钥不加入Git或测试报告；MockMvc禁止输出请求正文，供应商不会打印验证码、姓名、证件号或密钥。

最终运行结果由[验证记录](verification.md)及`docs/test-reports`归档。真实商户验收仍须在有权限的实际账户上核对短信到达、微信支付/退款、实名与收款人匹配、确认收款及真实银行/税务事实；本用例提供受控协议及业务分支证据，不冒充这些事实。
