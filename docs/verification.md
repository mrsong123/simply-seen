## 后端关键断言

- 同一幂等请求只生成一笔订单；同键不同内容拒绝，报价消费后不能另键重复使用。
- 未付取消恰好释放一次库存和积分；已支付超时扫描不误释放。
- 50次重复支付确认只发生一次库存扣减与赠分；错金额拒绝。
- 价格由服务端读取，报价后变价拒绝，积分不足和超过抵扣上限拒绝。
- 二级归因按父/祖父冻结，只有支付后计佣，受商品毛利和月预算约束。
- 连续三次部分退款加重复成功通知，不超过现金、积分和商品数量上限。
- 出款后发生来源退款生成追偿负债，不产生负可用余额。
- 提现不能超用余额，同一人不能审核并执行，重复到账事件不重复核销。
- 会员不能读他人订单，会员令牌不能调用财务管理权限。
- 月结不重复创建，同人复核拒绝，审批后只入账一次。
- 错误密码不会回滚限流计数；账本重建可发现人工制造的差异。
- 12个并发请求竞争5件库存，只有5次预占成功，库存与订单一致。
- RSA签名篡改、过期、错误平台序列号和AES-GCM认证失败均拒绝。
- 物流响应只暴露时间与轨迹，查无记录不展示为签收成功。

## 浏览器实际执行路径

创建测试会员 → 保存地址 → 商品详情 → 加入购物袋 → 实时报价 → 幂等创建订单 → 显式开发测试付款 → 管理员登录 → 发货 → 用户确认收货 → 申请退款 → 财务审核 → 显式开发退款确认 → 用户看到已退款 → 后台对账 → 导出商品CSV。
